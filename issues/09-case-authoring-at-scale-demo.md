# Slice 9 — Case authoring at scale + recorded-fixtures demo

## Parent

PRD #1

**Type:** HITL  ·  **GitLab:** #10  ·  **PRD user stories covered:** 7, 8, 9, 42, 43, 44, 53, 54

## What to build

Author the real dataset at scale and produce the demonstration. Generate ~400 command/control cases via LLM synthesis using a model family different from every target, then human-verify. Hand-author the high-value safety / ambiguous / out_of_scope cells; enforce the no-pure-templating rule in review. Record model-response fixtures so the demo is deterministic. Run the benchmark across model tiers and produce the scorecard showing the benchmark discriminates between them.

## Acceptance criteria

- [ ] ~400 human-verified command/control cases exist, with scarce hand-authored budget spent on safety/ambiguous/out_of_scope cells
- [ ] Synthesized cases were generated by a model family different from every target and human-verified; no pure templating
- [ ] Model-response fixtures are recorded so the demo run is deterministic and free to re-run
- [ ] The demonstration runs across at least three model tiers and the report shows statistically resolved differences (discrimination)
